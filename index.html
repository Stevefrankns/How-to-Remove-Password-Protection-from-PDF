How to Remove Password Protection from a PDF — Free Methods

Whether you've forgotten the password to your own document or need to strip restrictions for archiving, this guide covers the safest free methods to unlock PDFs.

Editorial Team • Updated May 2026 • 8 min read
Quick Answer

To remove a PDF password quickly: If you know the password, open the PDF in a browser (like Chrome), select "Print", and choose "Save as PDF". This strips the encryption. If you don't know the password, you can only bypass "Permissions" (editing/printing restrictions) using free online unlocking tools. A lost "Open" password (required to view the file) cannot be removed legally without professional forensic software.

Why PDF Passwords Matter (and Why We Remove Them)

PDF password protection is a standard feature for securing sensitive office files. However, there are perfectly legitimate reasons to ask how to remove password protection from a PDF file. You might be archiving old tax returns, migrating content to a secure cloud server, or sharing a document internally where password barriers are no longer necessary.

Important Legality & Ownership Note: This guide strictly covers removing passwords from documents you own or have authorized access to. We do not provide instructions, tools, or support for bypassing security on unauthorized, leaked, or maliciously obtained files.

Permissions Password vs Open Password — Explained

Before attempting to remove a PDF password, you must identify which type of lock is on your document:

  • Document Open Password: Requires a password just to open and view the file. This uses heavy encryption (like AES-256). If you lose this password, free tools cannot help you.
  • Permissions Password (Master Password): You can read the document, but you cannot print, copy text, or edit it. This restriction is easily stripped by dozens of free tools and browser tricks.

How to Remove Password Protection from PDF for Free

Below are the most reliable, free methods to take password protection off a PDF, organized by the tools you likely already have installed.

Method 1: The Browser "Print to PDF" Trick (No Software)

This is the most common native OS method. It works beautifully if you know the password and just want to remove the restriction for future use.

  1. Open Google Chrome or Microsoft Edge.
  2. Drag and drop your password-protected PDF into the browser window.
  3. Enter the password when prompted to view the document.
  4. Press Ctrl + P (Windows) or Cmd + P (Mac) to open the print dialog.
  5. Change the destination printer to "Save as PDF".
  6. Click Save. The newly created file will be an exact duplicate, but completely unprotected.

Note on compliance: This method strips all metadata and digital signatures. If the document is legally binding, stripping the signature may invalidate it.

Method 2: Remove PDF Password in Adobe Reader / Acrobat

If you have Adobe Acrobat Pro installed (or an older version of Acrobat), you can remove the security settings natively. (Note: The free Adobe Acrobat Reader does not allow you to remove passwords, only view them).

  1. Open the PDF in Adobe Acrobat and enter the password.
  2. Go to Tools > Protect > Encrypt > Remove Security.
  3. If the document has a Permissions password, you will be prompted to enter it now.
  4. Click OK to confirm removal, and save the file.

Method 3: Remove PDF Password on Mac (Preview)

Mac users don't need third-party tools; the built-in Preview app handles this seamlessly.

  1. Double-click the PDF to open it in Preview.
  2. Enter the password to unlock the document.
  3. Go to File > Export... (Do not use Export as PDF).
  4. In the dialog box, ensure the "Encrypt" checkbox is unchecked.
  5. Click Save. The new file will be unprotected.

Method 4: Remove PDF Password Online — Best Free Tools

If you cannot install software and the browser trick fails, online tools like Smallpdf or iLovePDF can strip permissions passwords instantly.

  • How it works: Upload your file to their secure server. If it's a permissions lock, the tool strips it immediately. If it's an open lock, you must provide the password, and the tool returns a clean file.
  • Security Warning: Never use online tools for documents containing PII (Personally Identifiable Information), financial data, or classified office files. Once uploaded, you lose control over the file's lifecycle.

Troubleshooting & Edge Cases

What to Do If You Forget a Document Password

If you have lost the "Open" password for a PDF you own, you are in a tough spot. Standard tools to remove password protection from a PDF file rely on you entering the password once. Without it, your only legal recourse is to search your archives for an unprotected original, or use commercial password recovery software that attempts to brute-force the password using variations you provide.

How to Print a Password-Protected PDF

If the print icon is grayed out, the document has a permissions password. You can bypass this by uploading the document to Google Drive. Double-click the file in Drive to open the previewer, then click the Print icon from the Google Drive interface. Google often ignores standard local print restrictions.

Frequently Asked Questions

Is it legal to remove password protection from a PDF?
Yes, it is entirely legal to remove password protection from documents that you own or have explicit authorization to modify. It is illegal and unethical to bypass security on documents you do not have permission to access.
How to remove PDF password protection online safely?
If you must use an online tool, ensure they explicitly state they delete files from their servers immediately after processing. However, the safest method is always to perform the removal locally using Chrome, Mac Preview, or Adobe Acrobat.
Is PDF password protection the same as encryption?
Not always. A "Permissions" password does not encrypt the file content; it just tells the PDF viewer to disable certain buttons. An "Open" password usually applies AES encryption to the file data itself. This is why Permissions passwords are easy to bypass, but Open passwords are not.
Can Google open a password-protected Office file?
If it is a permissions lock, Google Drive's previewer can often display and print the file. If it has an open lock, Google Drive will prompt you to enter the password before it can render the preview.

Our Verdict

Removing a password from a PDF is a simple process if you know the password or if it's merely a printing restriction. Using the browser "Print to PDF" trick is the fastest, safest free method available.

However, relying on individual PDF passwords for long-term document security is flawed. Passwords get forgotten, and permissions are easily bypassed. We highly recommend transitioning your sensitive PDFs into an encrypted container using dedicated, cross-platform security software.
